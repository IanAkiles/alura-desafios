# Desafios de programação da Alura

Dois desafios de calculadora no terminal e uma lista de tarefas com interface Tkinter. O código e os testes ficam em [`alura-desafios/`](alura-desafios/).

Abra um terminal nessa pasta e siga o [guia dos desafios](alura-desafios/README.md) para executar as atividades e os testes.
